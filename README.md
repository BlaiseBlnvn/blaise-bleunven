# BLAISE BLEUNVEN — site vitrine

Site statique multi-pages, conçu pour être publié sur GitHub Pages. Aucun framework ni étape de compilation n'est nécessaire.

## Pages
- `index.html` — Accueil
- `competences.html` — Compétences
- `realisations.html` — Réalisations
- `moyens-techniques.html` — Moyens techniques

## Publication sur GitHub Pages
1. Créer un dépôt GitHub, par exemple `blaise-bleunven`.
2. Envoyer tous les fichiers et dossiers de ce projet à la racine du dépôt (le fichier `index.html` doit être à la racine).
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. GitHub publiera le site à l'adresse `https://VOTRE-PSEUDO.github.io/blaise-bleunven/`.

Pour un domaine personnalisé, il sera possible de le configurer ensuite dans **Settings → Pages**.

## Modifications
- Les textes sont directement dans les fichiers HTML.
- Les styles sont centralisés dans `styles.css`.
- Les interactions simples du menu sont dans `site.js`.
- Les photos fournies sont dans `assets/images/`.

Le site utilise une police Google Fonts si le navigateur est connecté ; en cas d'indisponibilité, des polices système prennent le relais.
